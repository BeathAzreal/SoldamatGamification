# Oficina de Soldagem MIG/MAG — versões

Jogo didático de soldagem MIG/MAG em 3D, no navegador. Cada versão fica na
sua pasta, com o código-fonte e o jogo pronto.

| Versão | Pasta | Jogo pronto para baixar |
|---|---|---|
| **Alpha v1.3** (atual) | [`v1.3/`](v1.3/) | [`Oficina de Soldagem 3D Alpha v1.3.zip`](v1.3/Oficina%20de%20Soldagem%203D%20Alpha%20v1.3.zip) |
| Alpha v1.2 | [`v1.2/`](v1.2/) | pasta [`v1.2/jogo-portatil/`](v1.2/jogo-portatil/) |
| Alpha v1.1 | [`v1.1/`](v1.1/) | a própria pasta (só o jogo pronto, sem o código) |

**Baixar só a v1.3:**
- só o jogo: abra o `.zip` da tabela e clique em *Download raw file*;
- o projeto inteiro da v1.3 (código e jogo, sem as outras versões): use a
  branch `alpha-v1.3` e *Code → Download ZIP*.

Para jogar: descompacte e dê dois cliques em `Abrir o jogo.bat` (Chrome ou
Edge). Não precisa de internet nem instalar nada. Detalhes no `LEIA-ME.txt`
de cada versão e no `README.md` de cada pasta de código.
